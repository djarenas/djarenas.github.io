# Open-source packages

Other people have cats and dogs. I’m allergic, so these are my babies. Python tools I wrote and maintain, built for analyses where reproducibility and transparency matter. Both are free and open source.

## [eventus](eventus/eventus.md)

A framework for reproducible longitudinal cohort analysis. Every cleaning
decision is declared in a versioned config file, and every cleaner returns
the rows it rejected and why.

[Documentation](eventus/eventus.md) · [GitHub](https://github.com/djarenas/eventus) · GPL-3.0

## [Inter-Rater](interrater/interrater.md)

Agreement between raters for any rating task with no ground truth to check
against: systematic review screening, content coding, annotation quality,
evaluation panels.

[Documentation](interrater/interrater.md) · [GitHub](https://github.com/djarenas/Inter-Rater) · [PyPI](https://pypi.org/project/interrater/) · MIT
